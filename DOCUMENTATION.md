# Документация проекта testKeyfory

## Описание

Проект предназначен для управления услугами, заказами, материалами и взаимодействия между администраторами и исполнителями через веб-интерфейс и Telegram-бота.

## Структура проекта

### backend/ — Серверная часть (Node.js, Express)

- `index.js`, `server.js` — точка входа и запуск сервера
- **api/** — API-роуты и middleware
  - `route/RouteAdmin/` — роуты для админ-панели (управление услугами, материалами, заказами)
  - `route/RouteExecuter/` — роуты для исполнителей
  - `service/ServiceAdmim/` — бизнес-логика для админов
  - `service/ServiceExecuter/` — бизнес-логика для исполнителей
- **constants/** — константы статусов и другие
- **database/** — работа с БД, модели, миграции, сиды
- **scripts/** — миграции и вспомогательные скрипты
- **websocket/** — сервер для WebSocket-уведомлений
- **uploads/** — папка для загружаемых файлов
- **utils/** — утилиты

### bot/ — Telegram-бот для исполнителей

- `executerBot.js` — основной код бота (Telegraf)
- `constants/localization.js` — локализация сообщений

### frontend/ — Веб-интерфейс (React + Vite)

- **src/** — исходный код приложения
  - `components/` — общие компоненты
  - `Pages/` — страницы (аналитика, заказы, материалы, настройки и др.)
  - `constants/`, `lib/` — константы и вспомогательные функции
- **public/** — статические файлы
- `index.html`, `main.jsx` — точка входа

### docs/ — документация по отдельным частям

- `ADMIN_NOTIFICATIONS.md` — система уведомлений для админов
- `ENV_LOADING.md` — загрузка переменных окружения
- `REPLACEMENT_STATUS_FIX.md` — фиксы статусов замен

### Корневые файлы

- `docker-compose.yml`, `Dockerfile` — контейнеризация для запуска всех сервисов

## Основные функции

### Административная панель

- Управление услугами и их статусами
- Управление материалами и их распределением
- Мониторинг заказов и их выполнения
- Статистика и аналитика
- Управление исполнителями

### Telegram-бот для исполнителей

- Получение и выполнение заказов
- Управление материалами
- Запросы на замену материалов
- Статистика выполненных заказов
- Уведомления о новых заказах

### Веб-интерфейс

- Отдельные интерфейсы для админов и исполнителей
- Реалтайм-обновления через WebSocket
- Управление профилем и настройками
- Просмотр статистики и отчетов

## Технологии

### Backend

- Node.js и Express

- WebSocket для реалтайм-уведомлений

### Frontend

- React
- Vite для сборки
- WebSocket для обновлений
- Адаптивный дизайн

### Telegram Bot

- Telegraf фреймворк
- Интеграция с основным API

### Развертывание

- Docker и Docker Compose
- Nginx для проксирования (опционально)

## Запуск проекта

### Предварительные требования

1. Node.js 14+ и npm
2. Docker и Docker Compose
3. PostgreSQL (если запуск без Docker)

### Установка

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/RollSatrs/testKeyfory.git
   cd testKeyfory
   ```

2. Установить зависимости:

   ```bash
   # Backend
   cd backend
   npm install

   # Frontend
   cd ../frontend
   npm install

   # Bot
   cd ../bot
   npm install
   ```

3. Настроить переменные окружения:
   - Скопировать `.env.example` в `.env` для каждой части проекта
   - Заполнить необходимые переменные окружения

### Запуск через Docker

```bash
docker-compose up --build
```

### Запуск для разработки

1. Backend:

   ```bash
   cd backend
   npm run dev
   ```

2. Frontend:

   ```bash
   cd frontend
   npm run dev
   ```

3. Bot:
   ```bash
   cd bot
   npm run dev
   ```

## API Документация

### Админские эндпоинты

- `POST /api/admin/auth` - авторизация админа
- `GET /api/admin/stats` - статистика системы
- `POST /api/admin/executer-limits` - управление лимитами исполнителей
- `GET /api/admin/material-replacements` - запросы на замену материалов

### Эндпоинты исполнителей

- `POST /api/executers/auth` - авторизация исполнителя
- `GET /api/executers-bot/services/:id` - получение услуг
- `POST /api/executers-bot/request-replacement` - запрос замены материала
- `GET /api/executers-bot/stats/:id` - статистика исполнителя

## Обновление и поддержка

### Миграции базы данных

Для обновления структуры БД используются скрипты из папки `backend/scripts/`:

- `add_active_services_tracking.js`
- `add_executer_blocking_support.js`
- `add_executer_limits_table.js`
  И другие...

### Обновление системы

1. Получить последние изменения:
   ```bash
   git pull origin main
   ```
2. Обновить зависимости:
   ```bash
   npm install
   ```
3. Применить миграции:
   ```bash
   cd backend
   node scripts/apply-migrations.js
   ```

## Известные проблемы и решения

1. **Проблема с путями импорта**

   - Симптом: ERR_MODULE_NOT_FOUND при импорте между backend и bot
   - Решение: Использовать правильные относительные пути в импортах

2. **Синхронизация статусов**
   - Проблема: Рассинхронизация статусов заказов
   - Решение: Использовать константы из `statusConstants.js`
