## 🔧 Техническая реализация

### Логика наследования при замене материалов

При замене материала новый материал наследует:

- `order_number` от старого материала
- `executer_id` от старого материала
- `executer_name` от старого материала
- Получает статус `'использован'`

Старый материал:

- Получает статус `'заменен'`
- Очищаются поля `order_number`, `executer_id`, `executer_name`

### Фильтрация для бота

Бот исключает из выдачи материалы со статусом `'заменен'` через:

```javascript
status: { [Op.ne]: MATERIAL_STATUS.REPLACED }
```
