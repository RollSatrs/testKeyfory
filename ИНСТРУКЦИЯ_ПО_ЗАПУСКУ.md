# 🚀 ИНСТРУКЦИЯ ПО ЗАПУСКУ ПРОЕКТА KEYFORY

## 📋 КРАТКОЕ ОПИСАНИЕ ПРОЕКТА

**Keyfory** - это полнофункциональная платформа для управления цифровыми услугами, состоящая из:

1. **Backend API** (Node.js + PostgreSQL) - сервер с базой данных
2. **Frontend Panel** (React) - административная панель для управления
3. **Telegram Bot** - интерфейс для исполнителей заказов

---

## 🛠️ ПРЕДВАРИТЕЛЬНЫЕ ТРЕБОВАНИЯ

### Установленное ПО:

- ✅ **Node.js** v18+ [скачать](https://nodejs.org/)
- ✅ **PostgreSQL** v12+ [скачать](https://www.postgresql.org/download/)
- ✅ **Git** [скачать](https://git-scm.com/)

### Проверка установки:

```powershell
node --version    # должно показать v18.0.0 или выше

```

## 📦 ПОШАГОВАЯ УСТАНОВКА

### ШАГ 1: Клонирование проекта

```powershell
git clone https://github.com/RollSatrs/testKeyfory.git
cd testKeyfory
```

### ШАГ 2: Установка зависимостей

**Для всех модулей сразу:**

```powershell
# Установка для backend
cd backend
npm install

# Установка для frontend
cd ../frontend
npm install

# Установка для bot
cd ../bot
npm install

# Возвращаемся в корень проекта
cd ..
```

### ШАГ 3: Настройка базы данных PostgreSQL

1. **Запустите PostgreSQL** (обычно автоматически запускается как служба Windows)

2. **Подключитесь к PostgreSQL:**

```powershell
psql -U postgres
```

3. **Создайте базу данных:**

```sql
CREATE DATABASE keyfory;
CREATE USER keyfory_user WITH PASSWORD 'keyfory_password';
GRANT ALL PRIVILEGES ON DATABASE keyfory TO keyfory_user;
\q
```

### ШАГ 4: Настройка переменных окружения

1. **Скопируйте файл примера:**

```powershell
copy .env.example .env
```

2. **Отредактируйте файл `.env`** в корне проекта:

```env
# База данных
DB_HOST=localhost
DB_PORT=5432
DB_NAME=keyfory
DB_USER=keyfory_user
DB_PASSWORD=keyfory_password

# API сервер
PORT=3000
NODE_ENV=development
API_URL=http://localhost:3000

# JWT секрет (измените на свой!)
JWT_SECRET=your_super_secret_jwt_key_change_this_123456

# Telegram Bot (получите токен у @BotFather)
BOT_TOKEN=your_telegram_bot_token_here

# Frontend
VITE_API_URL=http://localhost:3000
```

### ШАГ 5: Создание Telegram бота (опционально)

1. Найдите **@BotFather** в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям и получите токен
4. Добавьте токен в файл `.env` как `BOT_TOKEN`

## 🚀 ЗАПУСК ПРОЕКТА

### Для разработки (3 терминала):

**Терминал 1 - Backend API:**

```powershell
cd backend
npm run dev
```

Сервер запустится на http://localhost:3000

**Терминал 2 - Frontend Panel:**

```powershell
cd frontend
npm run dev
```

Панель админа откроется на http://localhost:5173

**Терминал 3 - Telegram Bot:**

```powershell
cd bot
npm run dev
```

Бот станет активным в Telegram

### Для продакшена:

```powershell
# Сборка frontend
cd frontend
npm run build

# Запуск backend в продакшене
cd ../backend
npm run prod

# Запуск бота в продакшене
cd ../bot
npm run prod
```

## 🐞 РЕШЕНИЕ ПРОБЛЕМ

### 1. Ошибка подключения к базе данных:

```
ECONNREFUSED 127.0.0.1:5432
```

**Решение:**

- Убедитесь, что PostgreSQL запущен
- Проверьте настройки в файле `.env`
- Проверьте существование базы данных `keyfory`

### 2. Порт уже занят:

```
Error: listen EADDRINUSE :::3000
```

**Решение:**

```powershell
# Найти процесс на порту 3000
netstat -ano | findstr :3000
# Завершить процесс (замените PID на реальный)
taskkill /PID 1234 /F
```

### 3. Модули не найдены:

```
Cannot find module 'express'
```

**Решение:**

```powershell
# Переустановить зависимости
rm -rf node_modules
rm package-lock.json
npm install
```

### 4. Ошибки CORS:

```
Access to fetch blocked by CORS policy
```

**Решение:**

- Убедитесь, что backend запущен на порту 3000
- Проверьте настройки CORS в `backend/api/server.js`

## 📞 ПОДДЕРЖКА

### Если что-то не работает:

1. **Проверьте логи** в консоли всех 3 терминалов
2. **Убедитесь в последовательности запуска:**
   - Сначала PostgreSQL
   - Затем Backend
   - Потом Frontend
   - И наконец Bot
3. **Проверьте версии Node.js и npm**
4. **Убедитесь, что все порты свободны**
