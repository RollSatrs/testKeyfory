# 🤖 Полный функционал бота для исполнителей

## 📋 Описание работы системы

### 1. Процесс работы воркера с ботом:

1. **Старт работы**: Воркер запускает бота командой `/start`
2. **Выбор услуги**: Бот показывает только назначенные админом услуги
3. **Ввод номера заказа**: После выбора услуги воркер вводит номер заказа
4. **Получение материала**: Система привязывает номер заказа к первому доступному материалу услуги
5. **Работа с материалом**: Воркер может:
   - ✅ **Использовать** - копирует содержимое, фиксирует дату использования
   - 🔄 **Запросить замену** - отправляет запрос админу на замену

### 2. Что видит админ:

- В таблице материалов появляется колонка "Номер заказа"
- Статусы материалов обновляются в реальном времени
- Можно отслеживать какие материалы к каким заказам привязаны

## 🚀 Инструкция по запуску и тестированию

### Шаг 1: Запуск бэкенда

```bash
cd backend
npm start
```

### Шаг 2: Запуск фронтенда (в отдельном терминале)

```bash
cd frontend
npm run dev
```

### Шаг 3: Запуск нового бота (в отдельном терминале)

```bash
cd bot
node executerBotNew.js
```

### Шаг 4: Подготовка тестовых данных

1. **Войти в админку** (http://localhost:5173)
2. **Создать услугу** в разделе "Цифровые услуги"
3. **Добавить материалы** к этой услуге в разделе "Управление ключами"
4. **Создать исполнителя** в разделе "Исполнители"
5. **Назначить услуги исполнителю** через кнопку ⚙️ в таблице исполнителей

### Шаг 5: Тестирование бота

1. **Найти бота в Telegram** (по токену из .env)
2. **Отправить команду** `/start`
3. **Нажать "Начать работу"**
4. **Выбрать услугу** из доступных
5. **Ввести номер заказа** (любой текст/цифры)
6. **Проверить что материал выдался** с содержимым
7. **Протестировать кнопки**:
   - "Использовать" - материал должен стать "ИСПОЛЬЗОВАН"
   - "Запросить замену" - материал должен стать "НА ЗАМЕНУ"

### Шаг 6: Проверка в админке

1. **Обновить страницу** "Управление ключами"
2. **Проверить колонку "Номер заказа"** - должен появиться введенный номер
3. **Проверить статус материала** - должен измениться согласно действию в боте

## 📝 API Endpoints для бота

- `GET /api/bot/services/:telegramId` - Получить доступные услуги
- `POST /api/bot/assign-order` - Привязать номер заказа и получить материал
- `POST /api/bot/use-material` - Использовать материал
- `POST /api/bot/request-replacement` - Запросить замену материала
- `GET /api/bot/history/:telegramId` - Получить историю материалов

## 🔧 Настройки

Убедитесь что в `.env` файле указаны:

```
EXECUTER_BOT_TOKEN=ваш_токен_бота
API_URL=http://localhost:3000
```

## ⚠️ Важные особенности

1. **Номер заказа** - это просто текстовое поле, не создается отдельная запись заказа
2. **Материал резервируется** сразу при вводе номера заказа
3. **Один исполнитель** может работать только с назначенными ему услугами
4. **Материалы выдаются** по принципу FIFO (первый добавленный - первый выданный)
5. **Статусы материалов** обновляются мгновенно и видны в админке

## 🐛 Возможные проблемы

1. **"Услуга не назначена"** - нужно назначить услуги исполнителю в админке
2. **"Нет доступных материалов"** - нужно добавить материалы к услуге
3. **Бот не отвечает** - проверить токен бота и запущен ли бэкенд
4. **Ошибка авторизации** - убедиться что исполнитель создан и активен
