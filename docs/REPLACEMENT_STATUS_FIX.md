# Исправление отображения статуса замененных материалов

## Проблема

В таблице материалов (KeysMaterialsTable) материалы, которые были заменены, показывались как "Доступен" вместо "Заменен". Это происходило потому что:

1. После замены старый материал получает статус "доступен" в БД (для повторного использования)
2. Frontend брал статус прямо из поля `status` в БД
3. Frontend не проверял, есть ли для материала завершенная замена

## Решение

Обновлена логика отображения статуса в `KeysMaterialsTable.jsx`:

### Изменения:

1. **Добавлено состояние для замен**: `const [replacements, setReplacements] = useState([]);`

2. **Добавлена функция загрузки замен**:

```javascript
async function fetchReplacements() {
  const replacementsData = await apiFetch("/api/admin/material-replacements");
  setReplacements(replacementsData || []);
}
```

3. **Добавлена функция определения правильного статуса**:

```javascript
const getMaterialDisplayStatus = (material) => {
  // Проверяем, есть ли завершенная замена для этого материала
  const hasCompletedReplacement = replacements.some(
    (replacement) =>
      replacement.material_id === material.id &&
      replacement.status === "completed"
  );

  // Если есть завершенная замена - показываем "Заменен"
  if (hasCompletedReplacement) {
    return {
      text: "Заменен",
      color: "orange",
      originalStatus: material.status,
    };
  }

  // Иначе показываем обычный статус
  // ...остальная логика
};
```

4. **Обновлен рендеринг статуса**: Теперь использует `getMaterialDisplayStatus()` вместо прямого чтения из БД

5. **Улучшен tooltip**: Показывает дополнительную информацию о замене

## Логика работы

- **Обычные материалы**: Показывается статус из БД ("доступен", "использован")
- **Замененные материалы**: Показывается "Заменен" (оранжевый цвет), даже если в БД статус "доступен"
- **Tooltip**: Для замененных материалов объясняет, что материал был заменен и снова доступен

## API

Используется существующий endpoint: `GET /api/admin/material-replacements`

## Тестирование

- Материал ID 597 теперь правильно показывается как "Заменен"
- Замененные материалы имеют оранжевый цвет статуса
- Tooltip показывает дополнительную информацию о замене

## Преимущества

1. ✅ Пользователи видят что материал был заменен
2. ✅ В БД материал остается "доступен" для повторного использования
3. ✅ Экономия ресурсов - старые материалы не теряются
4. ✅ Прозрачность процесса замены
