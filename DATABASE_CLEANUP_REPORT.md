## Новая архитектура

### Упрощённая модель выполнения услуг:

```
Исполнитель → Услуга (executer_id) → ServiceExecution (order_number)
```

### Преимущества новой системы:

1. **Простота** - прямое назначение исполнителей к услугам
2. **Производительность** - меньше JOIN-запросов
3. **Масштабируемость** - чётко разделённые ответственности
4. **Отслеживаемость** - order_number в ServiceExecution и Material
